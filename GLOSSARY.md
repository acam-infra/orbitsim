# Glossary

| term | meaning |
|------|---------|
| **β (beta)** | angle between the Sun vector and the orbit plane; the only quantity the Earth umbra depends on |
| **LTAN** | Local Time of Ascending Node [h]; 06:00 = dawn–dusk, 10:30 = typical imaging, 12:00 = noon |
| **日影 / umbra** | the part of an orbit where Earth blocks the Sun (cylindrical model, penumbra ignored) |
| **日凌 / sun transit** | ground→satellite link outage when the Sun sits within ~0.5° of the line of sight |
| **SSO** | Sun-synchronous orbit; RAAN precesses 360°/year, inclination from J2 |
| **Walker-delta** | constellation shell: `planes` × `sats_per_plane` at one altitude/inclination |
| **base_ / exp_** | `base_*` = reusable scenario template (not runnable); `exp_*` = runnable experiment in `configs/` |
| **three seasons** | equinox (δ=0), summer solstice (δ=+23.44°), winter solstice (δ=−23.44°) |
